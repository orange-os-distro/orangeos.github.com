What comes with 1.0

A Mac way of working, on a Debian foundation.

Trackpad and Magic Mouse

Tap to click, two-finger scroll with natural direction, and secondary click set up on first boot.

Gestures

Swipe between Spaces with three fingers, pinch to zoom, and swipe up to see every open window.

Apps, not windows

⌘ Tab switches between applications. Closing the last window leaves the app running, the way you are used to.

Dock and menu bar

App menus live in the bar at the top. Running apps sit in the Dock with a dot underneath.

Quick Look

Select a photo, PDF or text file and press Space to see it without opening anything.

Familiar settings

Keyboard, Trackpad, Displays, Dock and Spaces are where you would look for them, with the same names.

Hardware

Built for Intel Macs from 2012 to 2017.

These are the machines Apple stopped updating but still have years left in them. Wi-Fi, input, audio and display have to work out of the box on every supported model.

MacBook Air2012 – 2017
MacBook Pro2012 – 2017
MacBook2015 – 2017
iMac2012 – 2017
Mac mini2012 – 2014
Mac Pro2013

This is the target range for 1.0. A model is listed as supported only after it passes the Orange Mac Experience certification suite, and newer Intel Macs are added the same way.

Updates

Debian security updates, straight from Debian.

OrangeOS does not repackage Debian. Your Mac talks to Debian's own servers for everything Debian ships, and to the Orange repository only for the pieces that make it feel like a Mac. Full upgrades keep the Orange packages in place.

Install

No Linux knowledge needed.

Download the ISO

Get the amd64 live image from the latest release on GitHub.

Write it to USB

Use any USB stick of 8 GB or more and a disk-imaging tool.

Boot from it

Hold ⌥ while the Mac starts and pick the EFI Boot drive.

Try, then install

The live session runs first. When everything works, click Install.

The 1.0 promise

On a supported Mac, OrangeOS will:

  • Boot the live ISO
  • Install without manual Linux steps
  • Bring up networking, keyboard, trackpad, audio and display
  • Receive Debian security updates
  • Keep Orange packages through full upgrades
  • Pass the Orange Mac Experience certification suite

What OrangeOS is not

OrangeOS copies behaviour, not code. It does not include macOS binaries, Apple artwork, or firmware it has no right to redistribute.

Apple services such as iMessage, FaceTime and Apple Pay are not supported and are not planned.

All branding is original, and every component is open source.

Give your Mac another decade.
